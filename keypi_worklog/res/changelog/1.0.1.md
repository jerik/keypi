# WorkLog v1.0.1

## Fixed

- **Reboot cut the working day short.** A restart during the day writes a
  stop and a start event into the log. The entry that started the working day
  ended at the reboot, so `09:02` with a reboot at `09:57` showed `0h 55m`
  instead of the time worked so far.

  The end of a session is now:

  | Situation | End of the session |
  |-----------|--------------------|
  | Start of the current day | the current time |
  | Start of a past day | the **last** stop event of that day |
  | Day ended after midnight | the next stop event in the log |
  | Machine never shut down | no end, the entry is marked accordingly |

  Every start event stays its own entry, so after a reboot the day is listed
  twice and the entry that really started the day can be picked.

- The description of today's entries reads `bis jetzt 16:39 · 7h 37m` instead
  of `läuft · bisher 7h 37m`, which was misleading for an entry that had been
  interrupted by a reboot.
