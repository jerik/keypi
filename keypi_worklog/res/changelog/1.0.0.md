# WorkLog v1.0.0

First release. Replaces the experimental `file_lookup` plugin.

## Features

- Keyword `wl` lists the recent logon events from the Windows event log
  export, newest first, with weekday, date, calendar week and duration
- Tab on an entry shows the working time with the configured break variants
  (default: no break, 1h, 1,5h)
- Enter appends the selected variant to the journal file:
  ```
  # Mi 2026-08-19 1709:44
  @arbeitsstunden am 2026-08-19: 7h
  ```
- Second action copies the entry to the clipboard instead of writing it
- Warns when the day already has an entry in the journal
- Shortcuts `#edit`, `#journal` and `#source`

## Details

- The working time is the difference between logon and logoff, rounded to
  the nearest 15 minutes. A session that is still open ends at the current
  time.
- The export has no year, so the year is derived from the sort order of the
  file. This keeps entries from the previous year on the correct weekday.
- Month and weekday names come from a lookup table instead of `locale`,
  which used to be set process wide and affected other plugins.
- Lines from other event sources are ignored, even when they contain the
  same wording ("Ein Dienst wurde erfolgreich gestartet").

## Fixed compared to `file_lookup`

- Wrong year and weekday for entries from the previous year
- `locale.setlocale()` side effect on the whole Keypirinha process
- Crash when the configuration held more or less than exactly one file
- Crash on a missing or unreadable log file
- Shell command built from the item description
- Blocking `subprocess.call()` on the UI thread
- File I/O on every keystroke, even outside the plugin
