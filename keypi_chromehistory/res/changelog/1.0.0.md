# Chrome History Plugin v1.0.0

**Release Date:** 2026-06-19

## New Plugin

First release of the Chrome History plugin for Keypirinha.

### Features
- Search Chrome browser history via keyword `ch`
- Fuzzy matching on page titles
- Open URL in default browser (Enter or Tab → Open in browser)
- Copy URL to clipboard (Tab → Copy URL)
- Fully configurable via `keypi_chromehistory.ini`

### Configuration
- `keyword` – Keypirinha trigger keyword (default: `ch`)
- `csv_path` – Path to preprocessed history CSV
- `url_filter` – Keep only URLs containing this pattern (empty = all)
- `[filter_out_titles]` – Title substrings to exclude
- `[filter_out_urls]` – URL substrings to exclude

### Preprocessing Script
- `chrome_history_preprocess.py` replaces the old CMD + pandas pipeline
- Pure Python (stdlib only, no external dependencies)
- Run via `uv run chrome_history_preprocess.py`
- Schedule via Windows Task Scheduler for automatic updates

### Bug Fixes vs. Old Plugin
- Fixed crash when page title contains `{` or `}` characters
- Removed hardcoded `c:\users\e17\` paths
- URL now stored in `data_bag` (not overloaded onto `short_desc`)
