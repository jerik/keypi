# Changelog - Mindbox Plugin v1.0.0

**Release Date:** 2026-02-09

## New Features
- **Initial Release:** Mindbox file browser plugin
- **Browse .mb files** from a configured local folder
- **Filter files** by typing in Keypirinha (live filtering by filename)
- **Open files** with the default Windows editor (Enter)
- **Display format:** Filename + modification date
- **#edit shortcut** to open configuration file
- **Configurable keyword** (default: `mb`)
- **Configurable folder path** for .mb files

## Testing
- 22 unit tests covering folder scanning, shortcut handling, and configuration
