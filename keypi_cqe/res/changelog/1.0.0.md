# KeyPi-CQE Changelog

## Version 1.0.0 (2025-01-21)

### Initial Release - Confluence Query Explorer

**Major Features:**
- ✅ Query Confluence Cloud using CQL (Confluence Query Language)
- ✅ Two-phase workflow: CQL input mode → Filter results mode
- ✅ Configurable keyword (default: `cqe`)
- ✅ Local filtering of search results (no additional API calls)
- ✅ Open Confluence pages directly in browser

**Workflow:**
1. **Invoke Plugin**:
   - Type `cqe` in Keypirinha (or your configured keyword)

2. **Enter CQL Query**:
   - Type your CQL query (e.g., `type=page AND space=MYSPACE`)
   - Press Enter to execute

3. **Filter Results**:
   - Results are displayed and cached
   - Type to filter results locally (instant, no API calls)
   - Select a result and press Enter to open in browser

**Configuration:**
```ini
[main]
# Your Confluence Cloud instance URL
confluence_url = https://your-domain.atlassian.net

# Your Atlassian account email
atlassian_email = your-email@example.com

# Your Atlassian API token
atlassian_api_key = your-api-token-here

# Keyword to trigger the plugin (default: cqe)
keyword = cqe
```

**CQL Query Examples:**
```
# Find all pages in a space
type=page AND space=MYSPACE

# Search by title
type=page AND title~"Setup"

# Find recent pages
type=page AND created >= "2025/01/01"

# Combine conditions
type=page AND space=DOC AND title~"API"
```

**Technical Implementation:**
- Plugin architecture: Keypirinha Plugin API
- API endpoint: Confluence Cloud REST API v1 (`/wiki/rest/api/content/search`)
- Authentication: Basic Auth (Email + API Token)
- Two-phase workflow prevents excessive API calls
- Local filtering for instant results
- Comprehensive error handling (auth, network, API errors)

**Acceptance Criteria Met:**
1. ✅ Plugin accessible via `cqe` keyword (configurable)
2. ✅ CQL query input mode
3. ✅ Query execution with Enter key
4. ✅ Results display with error handling for empty results
5. ✅ Local filtering via Keypirinha input
6. ✅ Browser opening on result selection
7. ✅ Shared configuration with Jira plugin (same API credentials)

**Benefits:**
