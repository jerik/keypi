# Version 1.3.0 (2026-02-03)

## Query History Feature

### New Features
- **Query History**: Access your recently executed CQL queries via `#history` or `#his`
- **Virtual Query Mode**: Tab on history entry executes query directly and shows results
- **History Clear**: `#history clear` deletes all history entries
- **Persistent Storage**: History is saved in JSON file and survives restarts
- **Configurable Limit**: Set maximum number of history entries (default: 30)
- **Duplicate Handling**: Re-running a query moves it to the top instead of creating duplicates

### Configuration
New configuration option in `keypi_cqe.ini`:
```ini
[main]
history_max_entries = 30
```

### Usage
1. Type `cqe` → `#history` to see recent queries
2. Select a query and press **Tab** to execute directly
3. Or press **Enter** to open CQL search in browser
4. Use `#history clear` to delete all history

### Technical Details
- History file: `%APPDATA%\Keypirinha\User\keypi_cqe_history.json`
- 32 new unit tests for history functionality
- Case-insensitive duplicate detection
- Graceful handling of corrupted history files
