# KeyPi-CQE Changelog

## Version 1.2.0 (2026-01-26)

### CQL Shortcuts Feature

**Major Features:**
- CQL Shortcuts for frequently used queries
- `#` prefix for shortcut access (e.g., `#myco`, `#mytodo`)
- `#edit` opens config file for easy editing
- List all shortcuts by typing just `#`
- Case-insensitive shortcut matching

**Workflow:**
1. **Define Shortcuts** in `keypi_cqe.ini`:
   ```ini
   [cqe_shortcuts]
   myco = title ~ konzept and creator = currentUser()
   mytodo = title ~ todo and creator = currentUser()
   recent = lastModified >= now("-7d") ORDER BY lastModified DESC
   ```

2. **Use Shortcuts**:
   - Type `cqe` → `#` to see all shortcuts
   - Type `cqe` → `#myco` to filter/execute a specific shortcut
   - Select shortcut → `Enter` → Query executes

3. **Edit Shortcuts**:
   - Type `cqe` → `#edit` → `Enter` → Opens config file in default editor

**Technical Implementation:**
- New `ITEMCAT_SHORTCUT` category for shortcut items
- `_cql_shortcuts` dict stores shortcut name → CQL query mapping
- `_handle_shortcut_input()` method handles `#` prefix input
- Shortcuts loaded from `[cqe_shortcuts]` section in INI file
- Exact match shows CQL execute item directly
- Prefix match shows filtered list of matching shortcuts

**UX Improvements:**
- Updated hint text: "Enter CQL query or #shortcut..."
- Shortcuts show their full CQL query as description
- Direct execution without visible CQL expansion
- Consistent behavior with JQE shortcuts implementation

**Configuration Example:**
```ini
[main]
confluence_url = https://your-domain.atlassian.net
atlassian_email = your-email@example.com
atlassian_api_key = your-api-token
keyword = cqe

[cqe_shortcuts]
# Define your custom shortcuts here
myco = title ~ konzept and creator = currentUser()
mytodo = title ~ todo and creator = currentUser()
recent = lastModified >= now("-7d") ORDER BY lastModified DESC
```

**Benefits:**
- Save time with reusable query shortcuts
- No need to remember complex CQL syntax
- Easy to edit and share shortcuts
- Case-insensitive matching for convenience

**Breaking Changes:**
- None - fully backward compatible

---

**Upgrade Notes:**
- Add `[cqe_shortcuts]` section to your `keypi_cqe.ini` if you want to use shortcuts
- Existing configurations will continue to work without modifications
