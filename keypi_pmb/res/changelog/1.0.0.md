# PM-Buddy Plugin v1.0.0

**Release Date:** 2026-02-19

## Initial Release

### Features
- Search Jira tickets and Confluence pages from the pm-buddy knowledge graph
- Two-phase workflow: type query → Enter → results appear → type to filter locally
- Multi-action support (Tab menu):
  - **Open** — open URL in browser (default action, Enter)
  - **Copy URL** — copy URL to clipboard
- `#edit` shortcut to open configuration file
- Direct SQLite access — no pm-buddy Python package required
- Type-aware ranking: initiatives and epics rank higher than stories/tasks
- Chrome visit recency boost (same as pm-buddy search engine)
- Hidden nodes filtered out automatically
- Local result filtering by title, key, status, assignee, or tags
- Configurable keyword (default: `pmb`)
- Environment variable expansion in `db_path` (e.g. `%USERPROFILE%`)

### Configuration
Create `%APPDATA%\Keypirinha\User\keypi_pmb.ini`:
```ini
[main]
keyword = pmb
db_path = %USERPROFILE%\.pm-buddy\pm-buddy.db
```

### Result Display
- **Jira**: `KEY-123: [epic][Open] Title | Assignee: Max | Fix: 1.2.0`
- **Confluence**: `[SPACE] Title | Type: page | Modified: 2026-01-15`
