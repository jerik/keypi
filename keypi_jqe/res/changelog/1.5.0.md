# KeyPi-JQE Changelog

## Version 1.5.0 (2026-01-29)

### Virtual Query Mode for History Entries

**Major Feature:**
- **Virtual Query Mode** - Tab on history entry executes query and shows results directly in Keypirinha
- Seamless workflow: `#history` → Tab → See results → Filter → Open ticket
- No need to re-type queries from history

**Workflow:**
1. **Using Virtual Query Mode**:
   - Type `jqe` → `#history` → List of recent queries appears
   - Select query → **Tab** → Query executes → Results appear in Keypirinha
   - Filter results by typing → Select ticket → `Enter` → Opens in browser

2. **Alternative (Open in Browser)**:
   - Select query → **Enter** → Opens JQL search in Jira browser

**Changed Behavior:**
- Tab on history entry: Shows results in Keypirinha (NEW - Virtual Query Mode)
- Enter on history entry: Opens JQL search in browser (was: copy to clipboard)
- Copy JQL to clipboard: No longer available (trade-off for Virtual Query Mode)

**Technical Implementation:**
- Added `loop_on_suggest=True` parameter to history items - enables Tab chaining
- Changed `hit_hint` from `IGNORE` to `KEEPALL` - required for Tab to work
- Removed registered actions for history items - prevents action menu blocking Tab
- Virtual Query Mode detection via `items_chain[-1].category() == ITEMCAT_HISTORY`

**Key Learnings (Keypirinha API):**
For Tab to chain a suggestion item into `items_chain`, you need THREE parameters:
1. `args_hint=kp.ItemArgsHint.ACCEPTED`
2. `hit_hint=kp.ItemHitHint.KEEPALL`
3. `loop_on_suggest=True` (CRITICAL!)

Without `loop_on_suggest=True`, Tab on suggestions does nothing!

**Test Coverage:**
- 8 new unit tests for Virtual Query Mode
- Tests for: condition checking, edge cases (empty chain, wrong mode, wrong category)
- Total: 85 unit tests pass

**Benefits:**
- Instant query re-execution from history
- Stay in Keypirinha workflow (no browser needed for results)
- Filter results immediately after query
- Faster than re-typing queries

**Breaking Changes:**
- "Copy JQL to clipboard" action removed from history entries
- Enter now opens browser instead of copying to clipboard
