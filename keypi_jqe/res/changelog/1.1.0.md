# KeyPi-JQE Changelog

## Version 1.1.0 (2025-12-19)

### Two-Phase Filter Mode

**Major Features:**
- ✅ Two-phase query workflow (JQL Input → Filter Results)
- ✅ No API calls during JQL typing (prevents 400 Bad Request errors)
- ✅ Local filtering of cached results
- ✅ Configurable keyword (default: "jqe")
- ✅ Visual feedback for mode switching

**New Workflow:**
1. **JQL Input Mode**:
   - Type JQL query (e.g., "assignee = currentUser()")
   - No API calls while typing
   - Press Enter to execute query

2. **Filter Mode**:
   - Query results are displayed and cached
   - Type additional text to filter results locally
   - Case-insensitive search in: Ticket ID, Summary, Status
   - Press Enter to open selected ticket

**Benefits:**
- 🚀 Drastically reduced API calls (from >10 per query to 1 per query)
- 🔒 Better rate-limiting compliance
- ⚡ Faster local filtering vs. API requests
- 🎯 Quick navigation through large result sets

**Configuration:**
- New `keyword` option in `keypi_jqe.ini`:
  ```ini
  [main]
  keyword = jqe  # Customize to your preference
  ```

**Technical Implementation:**
- State machine with JQL_MODE and FILTER_MODE
- Result caching for current session
- `_filter_results()` method for local filtering
- Updated `on_suggest()` to prevent premature API calls
- Enhanced `on_execute()` for mode switching

**Acceptance Criteria Met:**
1. ✅ User can complete JQL input with Enter to switch to Filter mode
2. ✅ User can filter results by typing additional text
3. ✅ Keyword is configurable (default: "jqe")

**Performance:**
- API calls reduced by ~90% during typical usage
- Instant local filtering response time
- No network latency when filtering cached results

**Known Limitations:**
- Results cached only for current session (no persistence)
- Filter searches only in: Ticket ID, Summary, Status
- Maximum 50 results per query (inherited from v1.0.0)

**Breaking Changes:**
- None - fully backward compatible

---

**Upgrade Notes:**
- Existing configurations continue to work
- New `keyword` option is optional (defaults to "jqe")
- No action required for existing users
