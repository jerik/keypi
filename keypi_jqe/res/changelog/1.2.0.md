# KeyPi-JQE Changelog

## Version 1.2.0 (2025-12-22)

### JQL Shortcuts

**Major Features:**
- ✅ Define reusable JQL shortcuts in configuration file
- ✅ Access shortcuts with # prefix (e.g., #me, #open, #mytask)
- ✅ List all shortcuts by typing # alone
- ✅ Case-insensitive shortcut matching
- ✅ Special #edit shortcut to open config file

**New Workflow:**
1. **Define Shortcuts** in `keypi_jqe.ini`:
   ```ini
   [jql_shortcuts]
   me = assignee = currentUser()
   open = status = "Open"
   mytask = assignee = currentUser() AND status = "Open"
   ```

2. **Use Shortcuts** in JQL Mode:
   - Type `#` to see all shortcuts
   - Type `#me` to filter shortcuts
   - Press Enter to execute shortcut

3. **Quick Config Edit**:
   - Type `#edit` to open config file
   - Edit shortcuts directly
   - Reload plugin (Ctrl+Alt+R)

**Benefits:**
- 🚀 Save time with frequently used queries
- 🎯 No need to remember complex JQL syntax
- ✏️ Easy to edit and maintain shortcuts
- 💡 Share shortcuts across devices (sync config file)

**Configuration:**
```ini
# JQL Shortcuts - Quick access to frequently used queries
# Use shortcuts by typing # followed by the shortcut name (e.g., #me, #open)
# Shortcuts are case-insensitive
# Special shortcut: #edit opens this config file for editing
[jql_shortcuts]
me = assignee = currentUser()
open = status = "Open"
mytask = assignee = currentUser() AND status = "Open"
```

**Technical Implementation:**
- New item category: `ITEMCAT_SHORTCUT`
- Shortcut loading in `_load_config()`
- Shortcut detection in `on_suggest()` (# prefix)
- Direct execution without showing expanded JQL
- `_handle_shortcut_input()` method for suggestion generation
- Config file path resolution for #edit

**Acceptance Criteria Met:**
1. ✅ Shortcuts configured in INI file
2. ✅ Shortcuts accessible with # prefix
3. ✅ All shortcuts listed when typing #
4. ✅ Shortcuts execute JQL query directly
5. ✅ #edit opens config file

**Usage Examples:**
```
# Show all shortcuts
jqe → # → [list of all shortcuts]

# Filter shortcuts
jqe → #me → [shows 'me' and 'mytask' shortcuts]

# Execute shortcut
jqe → #me → Enter → [executes "assignee = currentUser()"]

# Edit config
jqe → #edit → Enter → [opens keypi_jqe.ini]
```

**Integration:**
- Works seamlessly with existing two-phase workflow (JQL → Filter)
- Shortcuts expand to JQL and execute → results appear in Filter mode
- Compatible with all existing features

**Breaking Changes:**
- None - fully backward compatible
