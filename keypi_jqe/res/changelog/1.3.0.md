# KeyPi-JQE Changelog

## Version 1.3.0 (2026-01-23)

### Multi-Action Support

**Major Features:**
- ✅ Multiple actions available for each ticket result
- ✅ Tab key opens action menu with available actions
- ✅ Default action (Enter) opens ticket in browser
- ✅ Copy URL action for quick clipboard access
- ✅ No mode reset when copying URLs (copy multiple tickets)

**New Workflow:**
1. **Execute Query**:
   - Type `jqe` → Enter JQL → Press Enter
   - Results appear

2. **Use Actions**:
   - Select ticket → Press **Enter** → Opens in browser (default)
   - Select ticket → Press **Tab** → Action menu appears
   - Choose action → Press **Enter** → Action executes

**Available Actions:**
- **Open ticket**: Opens Jira ticket in browser (default action)
- **Copy URL**: Copies ticket URL to clipboard

**Benefits:**
- 🚀 Quick access to common actions
- 📋 Copy URLs without opening browser
- 🔄 Copy multiple ticket URLs in one session
- 🎯 Consistent with Keypirinha action pattern

**Usage Examples:**
```
# Default action (Enter)
jqe → assignee = currentUser() → Enter → Select ticket → Enter
→ Opens ticket in browser

# Copy URL action (Tab)
jqe → assignee = currentUser() → Enter → Select ticket → Tab
→ Action menu appears → Select "Copy URL" → Enter
→ URL copied to clipboard (mode stays active for next copy)

# Multiple URLs
Select ticket 1 → Tab → Copy URL → Enter
Select ticket 2 → Tab → Copy URL → Enter
Select ticket 3 → Tab → Copy URL → Enter
→ All URLs copied without reopening query
```

**Technical Implementation:**
- Action registration in `on_start()` using `set_actions()`
- Action constants: `ACTION_OPEN`, `ACTION_COPY_URL`
- JSON serialization in `data_bag` for full issue data
- Extended `on_execute()` with action parameter checking
- Mode reset behavior: Reset after Open, Keep after Copy URL

**Code Changes:**
```python
# Action registration
self.set_actions(
    self.ITEMCAT_RESULT,
    [
        self.create_action(name="open", label="Open ticket"),
        self.create_action(name="copy_url", label="Copy URL"),
    ],
)

# Action handling
if not action:
    # Default action (Enter): Open ticket
    kpu.shell_execute(ticket_url)
    self._reset_to_jql_mode()
elif action.name() == self.ACTION_COPY_URL:
    # Copy URL to clipboard
    kpu.set_clipboard(ticket_url)
    # Don't reset - user might copy multiple URLs
```

**Acceptance Criteria Met:**
1. ✅ Tab key shows action menu
