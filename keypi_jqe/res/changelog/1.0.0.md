# KeyPi-JQE Changelog

## Version 1.0.0 (2025-12-17)

### Initial Release - MVP

**Features:**
- ✅ Keyword "jqe" activates plugin in Keypirinha
- ✅ JQL query input and execution
- ✅ Query Jira Cloud API with Atlassian API token
- ✅ Display results in Keypirinha as searchable list
- ✅ Result format: `TICKET-ID: [Status] Summary`
- ✅ Extract and display all required fields:
  - Ticket ID
  - Summary
  - Status
  - Priority
  - Creator
  - Assignee
  - Created Date
- ✅ Open selected Jira ticket in browser
- ✅ Configurable via INI file (API credentials)

**Technical Details:**
- Python 3 implementation
- Jira Cloud REST API v3 integration
- Basic Authentication (email + API token)
- Error handling for authentication, API errors, and network issues
- 10-second timeout for API requests
- Maximum 50 results per query
- No external dependencies (uses Python stdlib)

**Configuration:**
- Configure in `keypi_jqe.ini`:
  - `jira_url`: Your Jira Cloud instance URL
  - `atlassian_email`: Your Atlassian account email
  - `atlassian_api_key`: Your Atlassian API token

**Installation:**
- Via Keypirinha Package Control (recommended)
- Manual: Copy to Keypirinha's `InstalledPackages` folder

**Known Limitations:**
- Maximum 50 results per query
- No pagination support (yet)
- No query history (planned for Phase 2)
- No JQL shortcuts (planned for Phase 2)

**Future Enhancements (Phase 2):**
- JQL shortcuts in configuration
- Query history (last 10 queries)
- "hist" keyword for quick access to history
