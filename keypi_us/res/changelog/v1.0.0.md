# User Search (US) v1.0.0 - Initial Release

**Release Date:** 2026-02-05

## Features

### User Search via Jira Cloud API
- Search for users by name, email or username
- Results displayed as filterable list
- Format: `Display Name | email@company.com`

### Two-Phase Filter Mode
- Phase 1: Enter search term → Tab → API search
- Phase 2: Type to filter results locally (no additional API calls)
- Fast, responsive filtering of large result sets

### Multi-Action Support
- **Enter**: Teams Chat (default for users with email)
- **Tab+Enter**: Open Profile in browser
- For users without email: Profile is default action

### Teams Chat Integration
- Opens MS Teams chat via `sip:` protocol
- Requires user's email address (API dependent)
- Users without email show "nicht möglich - keine E-Mail"

### Configuration
- `#edit` shortcut to open config file
- Configurable keyword (default: `us`)
- Uses same Atlassian credentials as JQE plugin

## Technical Details

- **API Endpoint**: `/rest/api/3/user/search`
- **Max Results**: 50 per search
- **Timeout**: 10 seconds
- **Unit Tests**: 19 tests (filter logic + user parsing)

## Known Limitations

- Email availability depends on user's Atlassian privacy settings
- Some users may not have visible email addresses
- Max 50 results per search query
